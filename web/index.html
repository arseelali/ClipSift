Fast review without a heavy editor

Actual video playback

Preview videos in the app with selectable speed, per-speed frame rate settings, play/pause, fullscreen, and session mute.

Rename at review speed

Type a new name without the extension, press Enter, and ClipSift preserves the file extension while moving to the next file.

Skip and jump anywhere

Leave the rename box blank to skip. Use the file list and search box to jump directly to any media item in the folder.

macOS-native packaging

Build a signed app bundle and a drag-to-Applications DMG with custom installer artwork.

The loop

Open folder, preview, rename, repeat

01

Open a folder

Choose a media folder from the app menu or toolbar. Hidden files and macOS metadata files are ignored.

02

Preview in place

Photos render normally. Videos play in the preview pane and can be sped up or shown fullscreen.

03

Rename or skip

Enter the next clean filename or leave the box empty. The file list updates immediately after each rename.

macOS app and DMG output

The build script creates a macOS app bundle and a styled drag-to-Applications DMG. Icons and installer artwork are included in the repository.
